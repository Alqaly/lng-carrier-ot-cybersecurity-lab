# Contributing

Contributions are welcome when they improve technical accuracy, reproducibility or teaching quality.

A contribution should include:

1. the engineering reason for the change,
2. the implementation,
3. verification steps,
4. source references when describing real marine systems,
5. an updated diagram if the architecture changes,
6. a note describing any limitations.

Before submitting:

```bash
python3 tools/quality_gate.py
```

Do not add screenshots, diagrams or claims taken from vendor material without attribution and appropriate reuse rights.

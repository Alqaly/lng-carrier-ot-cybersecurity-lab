How to read the chronology

A transition is evidence, not merely color. Compare the chronology with Modbus packet timing, PLC state and process state. A burst of many transitions can indicate a real cascading process event, poor alarm design, or both.

Modbus TCP

Ethernet → IP → TCP → MBAP → Function → Address → Value

Cargo: TCP/5020 · PMS: TCP/5021 · Propulsion: TCP/5022. The I/O map gives each address operational meaning.

OPC UA

Endpoint → SecureChannel → Session → Namespace → NodeId → Value + Status + Timestamp

Browse the deployed OpenPLC address space. Never treat guessed NodeIds as commissioned data.

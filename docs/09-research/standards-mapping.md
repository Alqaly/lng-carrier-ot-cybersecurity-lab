# Standards and Guidance Mapping

The project uses standards as design/reference constraints; it does not claim certification or compliance.

## IMO maritime cyber-risk guidance

Used to structure risk-management and recovery thinking around shipboard operational technology.

## IACS UR E26 / E27

- **E26:** ship-level cyber resilience reference.
- **E27:** onboard systems/equipment cyber resilience reference.

Project use: zoning, controlled interfaces, asset/configuration thinking, recovery and component-level security requirements.

## IEC 62443

Project use: zones/conduits, least privilege, security levels as a teaching concept, secure remote access and lifecycle thinking.

## IEC 61162-460:2024

Current maritime-navigation Ethernet safety/security add-on to IEC 61162-450. The project teaches its architectural purpose but does not implement or claim a conformant 460 network.

## SIGTTO

Used for gas-carrier Cargo HMI, alarm-management and ESD/ship-shore safety context.

## Status labels

Every standards-related claim should be classified as one of:

- **Implemented concept** — e.g. explicit zone/conduit policy.
- **Teaching reference** — e.g. IEC 61162-460 secure marine network architecture.
- **Not claimed** — compliance, SIL, class/type approval, certified ship-shore link.

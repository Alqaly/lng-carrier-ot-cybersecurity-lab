# 10 — Detection and Incident Reconstruction

## Why this matters

The goal is not to generate more alerts. The goal is to reconstruct **what happened, where, when and why it mattered to the process**.

## Visual tour — use real evidence

The visuals for this chapter are generated by the running lab:

- Wireshark transaction decode,
- Zeek connection/Modbus logs,
- process timeline,
- PLC state,
- alarm chronology,
- historian trend.

Zeek reference: https://docs.zeek.org/en/lts/logs/modbus.html

Research basis: Müller, Ziras & Heussen (2022) found improved detection/classification when physical process data was integrated with network data in an ICS evaluation. DOI: https://doi.org/10.1109/SmartGridComm52983.2022.9961010

## Worked example A — unexpected Modbus source

The network policy defines the only expected Cargo PLC→I/O source. Zeek evidence shows a second client. The classifier can objectively label that source as outside ground truth.

This is a **network-origin** finding.

## Worked example B — sensor bias

Commands and source addresses are normal, but measured flow disagrees with a mass-balance estimate derived from tank inventory change.

This is a **process-integrity** finding.

The two detections answer different questions.

## Full investigation method

```text
Establish operational state
→ preserve packets/logs
→ compare command/output/feedback/measurement
→ identify first abnormal event
→ correlate alarm/history
→ classify affected conduit/process
→ contain safely
→ restore known configuration/state
→ explain evidence and limitations
```

## Experiment metrics

Depending on the scenario, the research layer can measure:

- detection latency,
- process response time,
- event-order accuracy,
- cross-layer reconstruction completeness,
- residual error,
- false positive/negative counts for a defined rule.

A metric is not reported unless its calculation and evidence are retained.

## Lab action

```bash
./labctl new-run EXP-UNEXPECTED-MODBUS-SOURCE
# collect evidence
./labctl evaluate <run-directory>
```

Then repeat with `EXP-CARGO-SENSOR-BIAS` and compare which evidence source was decisive.

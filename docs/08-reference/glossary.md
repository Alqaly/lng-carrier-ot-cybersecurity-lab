# Glossary

## Actuator
Device that changes a physical process.

## Alarm
Condition requiring operator awareness. An alarm is not automatically a trip.

## BOG
Boil-Off Gas.

## CAN
Controller Area Network.

## Command
Requested control action.

## Conduit
Defined communication path between zones.

## ESD
Emergency Shutdown.

## Feedback
Independent indication of equipment state.

## F&G
Fire & Gas detection.

## Historian
Time-series store for process/operational data.

## HMI
Human-Machine Interface.

## I/O
Inputs and outputs connecting control logic to process state.

## IAS
Integrated Automation System.

## Interlock
Logic that permits or prevents an action based on conditions.

## Modbus TCP
Modbus application protocol over TCP/IP.

## NMEA 0183
One-way serial marine data interface standard.

## NMEA 2000
CAN-based multi-device marine network standard.

## OPC UA
Industrial interoperability architecture and protocol family.

## Permissive
Condition that must be true before an operation is allowed.

## PLC
Programmable Logic Controller.

## PMS
Power Management System.

## Process
The physical/operational system being controlled or observed.

## Remote I/O
I/O equipment located away from the controller CPU and accessed via a network/fieldbus.

## SIS
Safety Instrumented System.

## Trip
Protective action intended to stop or isolate a process/equipment state.

## Zone
Group of assets with similar function/trust/security characteristics.

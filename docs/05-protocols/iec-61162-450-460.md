# IEC 61162-450 / 460

IEC 61162-450 defines Ethernet interconnection for multiple talkers/listeners in maritime navigation and radiocommunication systems.

IEC 61162-460 is an add-on for environments requiring higher safety/security and includes network/interconnection requirements and redundant-network considerations.

The project does not claim compliance.

The chapter exists to teach that marine navigation Ethernet has its own engineering and security context and should not be reduced to “normal office Ethernet.”

# CAN and J1939 — Machinery Network Concepts

## One-sentence purpose

CAN lets multiple embedded controllers share a robust broadcast bus; J1939 defines higher-layer conventions widely used in engines and heavy equipment.

## Memory model

```text
CAN = frame transport + arbitration
J1939 = meaning/conventions on top of CAN
```

Do not say “J1939 is the protocol used by the LNG carrier engine” unless the selected equipment documentation says so.

## Worked example — CAN arbitration

If two nodes begin transmitting together, the message with the dominant lower identifier wins arbitration without corrupting the frame. The losing node waits and retries.

## Software lab

On Linux:

```bash
sudo modprobe vcan
sudo ip link add dev vcan0 type vcan
sudo ip link set up vcan0
candump vcan0
```

In another terminal:

```bash
cansend vcan0 18FF50E5#0102030405060708
```

This teaches actual SocketCAN frame mechanics. It is **not** an NMEA 2000 or vendor engine implementation.

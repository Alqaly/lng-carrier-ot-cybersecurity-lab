# Protocol Map

## Visual sources

Protocol chapters use the official Modbus, OPC Foundation, NMEA and IEC sources plus packet captures generated by the running lab. The important visual is the real message and its process consequence, not a protocol-logo map.

| Interface | Protocol / signal | Course role |
|---|---|---|
| OpenPLC ↔ virtual I/O | Modbus TCP | process I/O |
| OpenPLC → historian | OPC UA | information integration |
| navigation replay | NMEA 0183 | marine navigation data |
| advanced navigation reference | NMEA 2000 | CAN-based marine network |
| advanced marine Ethernet reference | IEC 61162-450/460 | marine navigation Ethernet |
| OpenPLC Editor → Runtime | HTTPS / runtime API | engineering management |

The project does not claim these are the only protocols on an LNG carrier.

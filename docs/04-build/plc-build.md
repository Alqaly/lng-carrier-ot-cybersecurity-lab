# PLC Build

OpenPLC Runtime is used because it executes IEC 61131-3 programs and provides current Modbus and OPC UA integration options.

Official runtime:
https://github.com/Autonomy-Logic/openplc-runtime

## PLC project

The Structured Text source is:

```text
openplc/cargo/CargoControl.st
```

## I/O mapping

Recommended mapping:

| PLC symbol | Function | Virtual I/O |
|---|---|---|
| `DI_ValveOpenFB` | valve feedback | discrete input 0 |
| `DI_PumpRunFB` | pump feedback | discrete input 1 |
| `AI_LevelSource` | source level | input register 0 |
| `AI_LevelDestination` | destination level | input register 1 |
| `AI_Flow` | flow | input register 2 |
| `AI_Pressure` | pressure | input register 3 |
| `DO_Pump` | pump command | coil 0 |
| `DO_Valve` | valve command | coil 1 |

## Logic

The PLC program:

- checks transfer mode,
- checks safety state,
- opens the valve,
- starts the pump only after valve feedback,
- identifies command/feedback mismatch,
- exposes process variables for OPC UA.

## OpenPLC Editor

Current OpenPLC Runtime v4 uses project configuration generated by the Editor for features such as Modbus remote I/O and OPC UA.

Do not hand-edit runtime plugin configuration and assume it will remain persistent after deploying a new Editor project.
